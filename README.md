# دينتال شير

عرض تفاعلي عربي، من اليمين إلى اليسار، لمنصة تربط عيادة الأسنان بمختبر مركزي واحد ومتاجر مستقلة ومزودي أشعة وتقويم ومجتمع أطباء. البيانات كلها وهمية، والمبالغ بالدينار العراقي، والوقت بتوقيت بغداد.

## التشغيل

```bash
npm install
npm test
npm run dev
```

ثم افتح [http://localhost:3000](http://localhost:3000) واختر حساباً من صفحة الدخول.

## ما الذي يغطيه هذا البناء

- خمس وجهات للطبيب: الرئيسية، عيادتي، الخدمات، المتاجر، الملف الشخصي.
- مرضى، حجوزات مع منع التعارض، مخزن، مصاريف، مشتريات، ومركز الحالة.
- طلب مختبر أو CBCT أو OPG أو تقويم، مع موافقة مشاركة الحد الأدنى.
- سلة وتأكيد طلب وتتبع، ولوحات للمختبر والتاجر والمزوّد والإدارة.
- عزل العيادة على الخادم، لا بتصفية الواجهة فقط. الاختبارات في `tests/authorization.test.ts`.

الحفظ الحالي في ذاكرة عملية التطوير حتى يُستبدل بقاعدة بيانات. أعد تشغيل الخادم إذا تغيّر شكل البيانات الأولية.

## ما لم يُبنَ عمداً

لا بوابة دفع، ولا واتساب، ولا مرضى حقيقيون، ولا نشر عام للمجتمع، ولا تشخيص آلي. راجع `docs/OPEN_DECISIONS.md` قبل أي تشغيل فعلي.

عطّل الدخول التجريبي في أي بيئة لاحقة بضبط `DEMO_MODE=false`.
