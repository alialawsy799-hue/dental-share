# خطة ما قبل بيئة التجريب

1. استبدال `lib/demo/db.ts` بـ PostgreSQL مع ترحيل يبدأ من `docs/schema.sql`، وفهرسة المواعيد والطلبات.
2. إبقاء دوال `lib/domain` كما هي الطبقة التي تفرض الصلاحية، ووصلها بمستودع حقيقي بدل المصفوفات.
3. هوية حقيقية بدل كعكة `ds_actor`. إغلاق `/enter` عبر `DEMO_MODE=false`.
4. تخزين خاص للصور وPDF وSTL، مع روابط موقّتة. لا مسار عام للملفات الطبية.
5. تدقيق فتح الملف وتعديله ومشاركته من غير كتابة الملاحظة السريرية داخل سجل التدقيق.
6. إبقاء الدفع عند الاستلام والتحويل اليدوي إلى أن تُعتمد بوابة متاحة ومتوافقة. لا واتساب قبل مزود وموافقة تواصل.
7. اختبارات العزل الحالية تبقى بوابة الدمج. يُضاف اختبار اختراق قبل أي بيانات حقيقية.
8. فصل بيئة التجريب عن الإنتاج، وأسرار على الخادم فقط.

لا يُطلق المجتمع للعامة ولا تُربط بوابة دفع ضمن هذه الخطة قبل اعتماد القرارات المفتوحة.
